6. MATHEMATICAL GEOMETRIC DESCRIPTORS & EXTRACTED FEATURES
--------------------------------------------------------------------------------
The dataset utilizes deterministic computer vision feature extraction computed 
via OpenCV contour moments and geometric topology:

1. Aspect Ratio (AR):
   AR = Max(BoundingRect_Width, BoundingRect_Height) / Min(BoundingRect_Width, BoundingRect_Height)
   • Nuts & Washers : 0.90 <= AR <= 1.35
   • Bolts & Screws : AR >= 2.00

2. Circularity / Isoperimetric Quotient (C):
   C = (4 * PI * Area) / (Perimeter^2)
   • Washers : C >= 0.82 (Circular disc profile)
   • Hex Nuts: 0.65 <= C <= 0.80 (Hexagonal facets)

3. Solidity (S):
   S = Contour_Area / ConvexHull_Area
   • Measures structural concavity and outer thread indentation.

4. Inner-to-Outer Area Topology (Hole Ratio - HR):
   HR = Area(Inner_Hole_Contour) / Area(Outer_Contour)
   • Washers & Nuts : 0.12 <= HR <= 0.55 (Internal central clearance hole present)
   • Bolts & Screws : HR < 0.05 (Solid cylindrical/conical profile)

5. Tip-to-Head Profile Ratio (TR):
   TR = Mean_Width(First 15% of Shaft Length) / Mean_Width(Last 15% of Shaft Length)
   • Bolt  : TR > 0.65 (Blunt, uniform flat end)
   • Screw : TR < 0.45 (Sharp, tapering conical point)

7. PREPROCESSING & DATA AUGMENTATION PIPELINE
--------------------------------------------------------------------------------

A. Image Preprocessing Pipeline:
   1. Color Conversion   : BGR -> Grayscale (single channel 8-bit intensity).
   2. Noise Reduction    : 5x5 Gaussian Kernel Blur to eliminate high-frequency noise.
   3. Binarization       : Otsu's Global Adaptive Thresholding.
   4. Morphological Clean: Morphological Opening (kernel 3x3) -> Closing (kernel 5x5)
                           to fill internal pinhole voids and isolate distinct edges.
   5. Bounding Extraction: Minimum Area Rotated Bounding Rectangle (cv2.minAreaRect).

B. Augmentation Pipeline (for Machine Learning Robustness):
   • In-Plane Rotation   : 0° to 360° continuous rotation (orientation invariance).
   • Random Scaling      : 0.8x to 1.25x zoom (working distance invariance).
   • Brightness Jitter   : +/- 25% illumination variation.
   • Gaussian Noise      : Variance sigma = 0.02 added to simulate camera sensor noise.
   • Perspective Tilt    : Simulated 0° to 25° perspective distortion.

9. KNOWN DATASET EDGE CASES & MITIGATION STRATEGIES
--------------------------------------------------------------------------------

1. Tilted Nuts (Perspective Elliptical Projection):
   • Issue     : When a hex nut is viewed at a steep slant angle, the circular inner 
                 hole projects as an elongated ellipse, and outer facets resemble a shaft.
   • Mitigation: Fitted ellipse major/minor axis estimation and multi-threshold 
                 convexity defect analysis.

2. Highly Reflective Polished Chrome Fasteners:
   • Issue     : Specular highlights cause overexposed hot-spots inside binary masks.
   • Mitigation: Diffused polarization LED ring light and adaptive Otsu windowing.

3. Mixed Head Drives (Phillips vs Allen vs Hex Head Screws):
   • Issue     : Different drive head profiles alter tip-to-head ratio calculations.
   • Mitigation: Dual-ended profile scanning ensuring the sharp end is verified 
                 irrespective of whether the head is socket, pan, or countersunk.

10. DATASET EVALUATION BENCHMARKS & METRICS
--------------------------------------------------------------------------------

Evaluation metrics tracked across the dataset:
• Precision (P)         : TP / (TP + FP)
• Recall / Sensitivity  : TP / (TP + FN)
• F1-Score              : 2 * (Precision * Recall) / (Precision + Recall)
• Mean Inference Latency: Local Engine < 5.2 ms | Gemini Cloud AI ~ 850 ms
• Target Accuracy Goal  : > 96.5% overall multi-class classification accuracy
